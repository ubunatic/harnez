# 693 — harnez index: say when it replaces a hand-edited row and point at harnez:topic

**Status**: Open
**Priority**: P3 (Low)
**Severity**: Minor
**Category**: Agentic Ergonomics
**Related**: `internal/index/index.go` (`StudyTopic`), `docs/README.md` (topic override note), `docs/Markdown.md`

---

/goal `harnez index` stays authoritative for index files, and managed repos
learn how to follow it: when a run replaces existing row text, it says which
file changed and how to keep curated text (`<!-- harnez:topic: ... -->` in
the study); the bundled docs state the rule. Stop and report when blocked on
a user decision or denied permission.

## 1. Problem & Motivation
`harnez index` is authoritative: index rows come from the files, and repos
must follow it (user, 2026-10-03). In neus on 2026-10-03, `harnez index`
replaced two hand-written study rows in `docs/README.md` with the studies'
`**Scope**:` and H1 text. The run printed nothing about it, so the agent
first reverted the index instead of moving the text into the studies. The
override that solves this (`harnez:topic`) is documented only in harnez's
own `docs/README.md`, which managed repos never see.

## 2. Technical Specification / Findings
- `StudyTopic` priority: `harnez:topic` comment, then `**Scope**:`, then H1.
- Fix applied in neus (`a7c303f`): the curated text moved into
  `harnez:topic` comments; the index then reproduced it with no diff.

## 3. Implementation & Verification Plan
- When an index run changes the topic text of an existing row, print one
  line per row: file, and "add `<!-- harnez:topic: ... -->` to the study to
  set this text". Do not keep the old text: the index stays authoritative.
- Add a short rule to the bundled `docs/Markdown.md` (or IssueTracking.md):
  index files are generated by `harnez index`; edit the source file, never
  the index row; use `harnez:topic` for curated study topics.

Verify: hand-edit a study row, run `harnez index`, see the notice and the
row regenerated; the bundled doc carries the rule; `make test-q1` passes.
