# GPT-5.6 Terra model row audit

- Question: Are the `codex:terra:low` and `codex:terra:med` table claims supported by public, model-specific evidence?
- Method: Web-only review of OpenAI’s GPT-5.6 Terra API model card, GPT-5.6 launch page and current availability help page; searched for model-specific Go, terminal/TUI, SQL, latency, tool-use and reviewer evidence. Checked the exact identifier, supported effort labels and product routes separately.
- Findings:
  - OpenAI lists the exact model name and API ID `gpt-5.6-terra`; current docs also expose it in Codex. Model card: https://developers.openai.com/api/docs/models/gpt-5.6-terra ; availability: https://help.openai.com/en/articles/20001354-gpt-5-6
  - Terra supports `none`, `low`, `medium`, `high`, `xhigh`, and `max` effort in the API. Codex supports selectable effort, including low and medium. “EFF yes” is supported; low versus medium as token/cost effort categories has no public quantitative characterization located. https://developers.openai.com/api/docs/models/gpt-5.6-terra ; https://openai.com/index/gpt-5-6/
  - Product route verified only as OpenAI API and Codex. The API reference advertises hosted shell, apply patch, skills, MCP and other Responses API tools. Those are product capabilities, not proof of the separate `codex:` route configuration beyond Codex availability. https://developers.openai.com/api/docs/models/gpt-5.6-terra ; https://help.openai.com/en/articles/20001354-gpt-5-6
  - OpenAI describes Terra as balancing intelligence and cost and roughly corresponding to the mini tier of earlier GPT-5 families. The launch page reports family-level coding/agentic claims, but does not substantiate Terra-specific Go, TUI or SQL strength. No matched task benchmark or representative task set for these three areas was located.
  - “Best-value auditor,” “finds code traps with file:line,” and role suitability for advisor/reviewer/developer are operational quality claims. Public primary-source evidence found does not isolate Terra on code auditing, defect discovery, citation/file-line accuracy, or role-specific comparisons.
  - There is no public Terra-specific first-token latency measurement in the reviewed sources; the table does not make such a claim for Terra.
- Inconclusive: Public docs confirm identity, effort controls, broad route availability, tools and broad positioning. They do not establish the table’s comparative cost multiplier of 16, skills marks, role rankings, best-value judgment, or file:line auditor claim. Cost depends on metric and usage surface; API pricing is not a Codex quota multiplier.
