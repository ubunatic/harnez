## 4. Honest Post-Mortem (Failures, Bugs & Near-Misses)

1. **Shadowed `~/.local/bin/harnez` vs `make install` (`#1235` interaction, filed as `#1245`):** Since `goself` (`#1235`), `harnez install` places binaries in `~/.local/bin/harnez`, which precedes `~/go/bin` on `PATH`. Meanwhile `Makefile` `install` builds `./harnez` and writes `~/go/bin/harnez`. Verified live on `2026-11-19`: plain `harnez --version` printed `0.5.9` (`39,409,134` bytes in `~/.local/bin/harnez`) while `./harnez` and `~/go/bin/harnez` were `0.5.9+5387` (`39,491,601` bytes), forcing `./harnez` workarounds in sessions and stale `PATH` behavior if unspotted.
2. **Helper-level tests masking Cobra command dispatch (`#1202`):** In `M6`/`M7`, all unit tests passed while calling `edit`/`close`/`reopen` helpers directly, hiding that forge dispatch lived inside Cobra `Args`, causing `--dry-run` to execute the local `041: already Closed` fallthrough afterwards and causing `close --forge` with no args to slice-panic (`[2:1]`). Caught only by running the installed binary plus `forge-rev4` (`8d9a47c7`).
3. **Long-context caching cliff (`#1202`) and mid-session quota exhaustion (`Nov 19`):** Resumed multi-milestone workers in `#1202` hit `85x–89x` cached-to-new token ratios (`88k–90k` of `100k` context) before retiring (`forge-dev2`). ## 7. Key Learnings & Evergreen Upstream

- **Verify CLI dispatch, not helper units alone:** After tests pass on helpers, run every new/edited verb via the compiled binary (`--dry-run` / `--help`) to catch Cobra `Args` vs `RunE` bugs (`docs/practices/IssueTracking.md`, `docs/studies/2026-11-16-two-agent-lean-sprint-forge-filing.md`).
- **Enforce no-live-CLI rules structurally in tests:** Never rely on prompt wording alone; add package `TestMain` guards and mock shims on `PATH` so tests cannot touch external CLIs or shared user dirs.
- **Retire high-context developers cleanly:** Split work at natural milestone/review boundaries instead of resuming an `85k+` context worker that pays `85x` cached re-read amplification.
- **Keep `make install` and `goself` aligned on `PATH`:** Having two user binary locations (`~/go/bin/harnez` vs `~/.local/bin/harnez`) creates silent version split across sessions (`#1245`).
- **Close tickets in the merge PR:** Merge commits that land full functionality (`#1242` in PR `#184`, `#1240` in `74f06897`) should transition the ticket status before opening the PR so tracker state never lags `main`.
